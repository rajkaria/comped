Every Play

Twenty-one published rote Plays on three stdlib-only Python cores. No pip install, no node, no keys, and no network in any core. Each one is a public archive you can read before you run it.

How to run one

Every line on this page is complete. Paste it, and rote fetches the published archive, shows you a consent screen listing every file the Play touches, and runs it. It needs rote, the free runner from Modiqo, and a free account. If you have neither, the registry installs both and the Play in one go. Swap the name at the end for any Play on this page:

$curl -fsSL "https://play.modiqo.ai/install?play=rajkaria/comped" | sh

No account, no install, nothing kept. comped also has a door that needs neither. It downloads about 40 KB of stdlib Python to a temporary directory, runs it, and deletes itself:

$curl -fsSL https://gotcomped.com/comped.sh | sh

Prefer node? npx comped runs the same code. The full walkthrough is in the docs.

What your agents cost

Three Plays that read the transcripts your coding agents already write. Nothing is sent, nothing is guessed, and every number has a line showing the arithmetic behind it. Built on comped_core.

comped

What would this month have cost at list price, and how far ahead of your plan are you?

The card. List-price total for the window, the multiplier against the plan you actually pay for, your cache share, the delta since last time, the asks you keep repeating, and your rank on the board. It works out which AI you run from the model ids in the logs, so you type nothing.

$rote play run https://play.modiqo.ai/rajkaria/comped
$rote play run https://play.modiqo.ai/rajkaria/comped handle=yourname

Read the archive before you run it, or the full description.

session-ledger

One ledger, four harnesses, no double counting.

The primitive the other two are built on. Claude Code writes one line per content block, so roughly four in ten usage lines are streaming duplicates of the same API call. Codex writes cumulative counters. This collapses both into one deduplicated ledger, subagents included, and judges nothing.

$rote play run https://play.modiqo.ai/rajkaria/session-ledger

Read the archive before you run it, or the full description.

wrong-turns

What does your agent keep getting wrong, and what did recovering cost?

Tool calls that errored, the messages where you corrected it, and reverts. Grouped into recurring classes, counted across sessions and days, priced in tokens, one redacted line of evidence each, and a drafted CLAUDE.md rule for every class that recurred three times. It never edits your rules file.

$rote play run https://play.modiqo.ai/rajkaria/wrong-turns

Read the archive before you run it, or the full description.

What your machine has been hoarding

Six read-only scans of files your machine already keeps. No network, no credentials, and every one runs cold on bundled fixtures first so you can watch it work before you point it at anything of yours. Built on daily_core.

tab-debt

How many tabs are open, and how long since the oldest one was looked at?

The tab strip shows neither a number nor a date, but the session files your browser writes hold both. Chrome and its family, Firefox, Safari and Arc, read directly: Chrome session files are a binary command log and Firefox stores its session in a compressed container, so both readers were written from the format up.

$rote play run https://play.modiqo.ai/rajkaria/tab-debt demo=true

Read the archive before you run it, or the full description.

birthday-radar

Whose birthday is next, and how much of your address book has no date at all?

Your address book mentions a birthday on the morning of, which is the one moment the information is useless. This sorts by how soon, so the next one is a number of days. Contacts database, vCard exports and CSV, any one of which is enough.

$rote play run https://play.modiqo.ai/rajkaria/birthday-radar demo=true
$rote play run https://play.modiqo.ai/rajkaria/birthday-radar vcard_dir=~/Documents

Read the archive before you run it, or the full description.

app-graveyard

Which applications did you stop opening, and which are still Intel only?

macOS records the last time you opened every application and never shows you the list. This asks Spotlight, measures each bundle, and reads sixteen bytes into every executable to say which ones your Apple silicon Mac is still emulating.

$rote play run https://play.modiqo.ai/rajkaria/app-graveyard demo=true
$rote play run https://play.modiqo.ai/rajkaria/app-graveyard unused_days=180

Read the archive before you run it, or the full description.

vault-pulse

Which notes are load-bearing, which were written once, and is the daily habit alive?

A notes folder only grows, and nothing in the editor says which notes matter. The links give the graph and the timestamps give the habit. Orphans, broken links, and the daily-note streak. Obsidian is found automatically; any markdown folder works.

$rote play run https://play.modiqo.ai/rajkaria/vault-pulse demo=true
$rote play run https://play.modiqo.ai/rajkaria/vault-pulse vault=~/Notes

Read the archive before you run it, or the full description.

desktop-clutter

What is actually on the Desktop and in Downloads, by age and by size?

Both folders are append-only in practice, and the Finder sorts by name so the oldest file is invisible. Counted, aged, sized, duplicates found by hash, and graded A to F. On the machine this was built on it came back F with 164 duplicate groups.

$rote play run https://play.modiqo.ai/rajkaria/desktop-clutter demo=true

Read the archive before you run it, or the full description.

receipt-ledger

What do the receipt files you already have add up to?

PDF invoices, saved confirmation pages, exported messages and plain text, four formats in one folder that nobody opens one at a time. The PDF reader decodes ToUnicode maps and rebuilds lines from the text matrix. Currencies are totalled separately and never summed across each other, and a document has to prove it is a receipt before it counts.

$rote play run https://play.modiqo.ai/rajkaria/receipt-ledger demo=true
$rote play run https://play.modiqo.ai/rajkaria/receipt-ledger receipts_dir=~/Downloads

Read the archive before you run it, or the full description.

Ten seconds, many times a day

Twelve Plays small enough to run on reflex. Five of them remember what you told them in one append-only file under your home directory. None of them touch the network, and none of them take an out_dir, because these print. Built on micro_core.

whatis

What is that opaque string?

Paste it and it peels it. A base64 blob holding gzip holding JSON holding a JWT is one input and four layers, and you get all four. JWTs, base64, gzip, epochs, UUIDs, IPs, cron expressions and magic bytes.

$rote play run https://play.modiqo.ai/rajkaria/whatis text=aHR0cHM6Ly9nb3Rjb21wZWQuY29t

Read the archive before you run it, or the full description.

fits

Will this fit the window, and what will it cost?

Point it at text or a file. Bytes, lines and words are facts and it states them. The token figure is an estimate, so it prints a range and the method that produced it rather than asserting a number the stdlib cannot know.

$rote play run https://play.modiqo.ai/rajkaria/fits path=README.md

Read the archive before you run it, or the full description.

is-it-secret

What should you redact before pasting that?

Run it on anything about to leave your machine. It knows the literal shapes: AWS key ids, GitHub tokens including fine-grained ones, private key headers, connection strings. It hands back the same text with those parts replaced, and it never prints what it found.

$rote play run https://play.modiqo.ai/rajkaria/is-it-secret path=README.md

Read the archive before you run it, or the full description.

cron-when

When does that cron expression actually fire?

The English, the next five fires in your zone and in UTC side by side, and the daylight saving trap. When both day fields are restricted, cron takes the union rather than the intersection, which is the thing most readers get wrong.

$rote play run https://play.modiqo.ai/rajkaria/cron-when expr='0 3 * * 1' tz=Europe/London

Read the archive before you run it, or the full description.

punch

How many times was the day broken, and what was the longest block you got?

One line saying what you are doing, which takes two seconds. Do it a few times a day and it answers what a calendar cannot: not where the time went, but how often it was cut.

$rote play run https://play.modiqo.ai/rajkaria/punch note='writing the launch post'

Read the archive before you run it, or the full description.

spent

What went out today, and where does the month land?

One line in, a spend log that owes nothing to a bank, an app or an export. Amount, label, optional tag. Decimal arithmetic end to end, never a float.

$rote play run https://play.modiqo.ai/rajkaria/spent entry='320 lunch #food'

Read the archive before you run it, or the full description.

jot

The thought, into the vault, in two seconds.

A thought arrives while you are doing something else. One line and it is appended to a markdown file in your vault, timestamped, and you are back to what you were doing. No app to open, no place to decide on.

$rote play run https://play.modiqo.ai/rajkaria/jot note='ring the dentist'
$rote play run https://play.modiqo.ai/rajkaria/jot vault_dir=~/Notes

streak

How long is the run, and which weekday do you keep dropping?

One word, and it keeps the only part of habit tracking that changes behaviour: the current run, the record, a grid of the last twenty-one days, and the day of the week you keep losing.

$rote play run https://play.modiqo.ai/rajkaria/streak did=water

last-turn

What did the turn that just finished cost?

Not this month and not this project. That one turn, ninety seconds ago. Model, tokens in and out, cache share, dollars, and today's running total. It reads a 256 KB tail rather than your history, which is why it can run twenty times a day.

$rote play run https://play.modiqo.ai/rajkaria/last-turn

budget-left

How much of today's budget is gone, and how fast is it going?

You set a number you are willing to spend on agents today. This says how much is left, the burn rate, and whether you hit the cap before the day ends.

since-last

What did the agent actually touch?

Not what it said it did. What moved on disk since you last asked. Created, changed, deleted, and whether anything outside the repository moved. It watches the mtimes of the sensitive directories and can tell you something under one of them changed. It never opens them.

$rote play run https://play.modiqo.ai/rajkaria/since-last root=.

Read the archive before you run it, or the full description.

safe-to-commit

What is staged that should not enter history?

The last thing between a live credential and permanent git history is you, at the moment you type commit. It parses .git/index directly, with no subprocess: credentials, a tracked .env, leftover debugging, and files large enough to regret for the life of the repository.

$rote play run https://play.modiqo.ai/rajkaria/safe-to-commit repo=.
